# CLAUDE.md — Clank! Legacy Campaign Epilogues

## Project Overview

This project contains custom in-universe epilogues for a **Clank! Legacy: Acquisitions Incorporated** campaign. Each game session gets a field report written in the style of Acquisitions Incorporated corporate documents — dry humor, fantasy bureaucracy, and character-driven narrative.

The reports are written as markdown (`.md`) files and also rendered as styled HTML (`.html`) files with a parchment/fantasy aesthetic for sharing via WhatsApp or other channels.

## Reference Materials

- **Rulebook** (`resources/40-clank-legacy-acquisitions-incorporated-rulebook.pdf`): Full game rules. Use for mechanics reference — knockouts, Danger Zone, artifacts, scoring, contracts, etc.
- **Book of Secrets** (`resources/ClankLegacy_Book_Of_Secrets.pdf`): Contains all numbered passages (1–189) for the campaign story. Passages are referenced by number throughout this document.

## CRITICAL RULES FOR WORKING WITH THIS PROJECT

### No Spoilers
- **NEVER reveal story content from the Book of Secrets unprompted.** Only reference passages the user has already played through.
- When asking about passages, use only the passage NUMBER. Do not describe what happens in unplayed passages.
- If you need to confirm a passage with the user, be vague: "Passage 41 involves an abandoned location — does that sound right?" NOT "Passage 41 is where you find the haunted manor with the STAY AWAY warnings."
- The user will provide story details in their own words. Work from what they tell you.

### In-Universe Language
- Avoid board game terminology: no "cards," "draws," "scoring points," "Boots" (as a resource), "game."
- Use "mission" instead of "game."
- Use in-universe equivalents: "hired sword" instead of "card purchase," "tireless legs" instead of "Boots," etc.
- "Knocked out" is the correct term — the game never says "death" or "killed." Characters return next mission.
- Important distinction: knocked out ABOVE the Danger Zone = you still earn rewards. Knocked out IN the Danger Zone or without an artifact = nothing to show.
- Seals of Excellence, Contracts, Dran Enterprises, Associate Spotlight — these are all in-universe terms and CAN be used.

### Tone & Style
- Written as Acquisitions Incorporated field reports filed by "Regional Oversight on behalf of the field team."
- Dry corporate humor mixed with fantasy adventure.
- Each character has a distinct voice/running joke (see Franchise Details below).
- Home Office Notes section at the end provides meta-commentary in Omin Dran's corporate voice.
- "Come Back Next Mission For:" at the bottom mirrors the Book of Secrets format.

### HTML Style
- Parchment aesthetic: warm background gradient (#f4e4c1 to #e5d0a0), dark border (#8b7355), inner border accent.
- Fonts: Cinzel (headings), Crimson Text (body) — loaded from Google Fonts.
- Section titles: uppercase, letter-spaced, with bottom border.
- Dividers: `— ◆ —` between major sections.
- Home Office Notes: indented block with left border, italic.
- Dark outer background (#1a1410) framing the parchment.
- No page breaks — single continuous scroll for mobile sharing.

- Secret tunnels to the north (contracted since Game 1) never explored (Passage 37) — second X on Dran Enterprises track.
- Piko passed cauldron woman again — still no ingredients to give. Contract still unfulfilled.

**Results:** Bonkbeard 1st, Harry 2nd, Piko 3rd, Sir Prize 4th (0 points).

**Dran Enterprises Track:** Two X marks this mission (Sir Prize knockout + unexplored tunnels).

**Unresolved:** Cauldron contract (from Passage 9). Path sticker from Passage 8 still not placed.

## Running Themes (for future reports)

- **"Strategic Information Withdrawal"** — A pattern at The Drunken Dragon. Harry withheld a winning purchase in Game 1. Three teammates encouraged Sir Prize into a fatal detour in Game 2. Piko forgot the pickaxe. Information is the franchise's weapon of choice.
- **The Mountains** — Have claimed victims two missions running. Bonkbeard barely survived in Game 1. Sir Prize went down in Game 2. The mountains are becoming a recurring antagonist.
- **The Canoe** — Harry's signature move in Game 1. Abandoned by Harry in Game 2, stolen by Bonkbeard. Who will claim it in Game 3?
- **Dran Enterprises** — Growing shadow. Two X marks on the track already. Portentia is watching.
- **The Cauldron Woman** — Patient, but her stirring is slowing. Contract from Game 1 still unfulfilled heading into Game 3.
- **Bonkbeard's Redemption** — From last-place mountain climber in Game 1 to MVP in Game 2. The beard abides.
- **Sir Prize's Tragedy** — From Associate Spotlight hero in Game 1 to zero-point casualty in Game 2. Noble to a fault.

## Editorial Notes

- Reports should be roughly similar in length. Game 1 is the benchmark — tight and punchy. Game 2 can be slightly longer since more happened, but should not be significantly heavier.
- The "Home Office Notes" section should be the punchiest part — short paragraphs, corporate voice, dark humor.
- Each report ends with the "Come Back Next Mission For:" teaser matching the Book of Secrets epilogue format.
- When the user provides session details, ask for: character actions, waypoint numbers visited, key choices made, scores/placements, memorable moments. Do NOT list passage content when asking — let the user describe events in their own words.
